# Regenradar

Web-App mit Regenradar (RainViewer) auf einer Leaflet-Karte, aktuellem Wetter (Open-Meteo)
und Ortsnamen (Nominatim, Fallback BigDataCloud). Läuft im Browser auf Android, iOS und Desktop.

- Die App liegt komplett in `public/index.html`.
- Jeder Push auf `main` veröffentlicht sie über `.github/workflows/deploy.yml` auf GitHub Pages.
